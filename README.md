# 我们的游戏馆 — 7 个可联机游戏

包含：同词相遇、骗子酒馆、海战棋、双人代号、UNO 风格双人纸牌、恶魔轮盘风格虚拟概率游戏、双人简化斗地主。

## 本地

```bash
npm install
npm start
```

浏览器访问 `http://localhost:3000`。双方用房间码或分享链接加入同一个游戏。新游戏可以从 `arena.html?game=...` 访问。Node 18+。

## Railway

将本目录（保留 `server.js`、`multigames.js`、`package.json`、`public/`、`railway.json`）提交 GitHub，Railway 创建 **Deploy from GitHub repo**，生成公开域名。启动：`npm start`，端口使用平台提供的 `PORT`。

## Heroku

`heroku create`、`git push heroku main`，`Procfile` 已设为 `web: npm start`。

## 规则与范围

- **同词相遇**：双方每轮提交中文词语，逐轮联想直到词语相同。
- **骗子酒馆**：2–4 人，虚拟轮盘惩罚；出完最后一手后，对方仍可以质疑；若选择相信则本局结束并可重新发牌；胜利条件为最后一名存活者。
- **海战棋**：2 人，6×6 海域，分别放置 3/2/2 格舰船，轮流开火，击中对方全部 7 格获胜。
- **双人代号**：合作版，玩家 1 看得到六个目标词并给线索，玩家 2 猜词；最多猜错两次，第三次失败。
- **UNO 风格**：双人回合制，颜色/数字匹配；跳过、反转会让出牌者继续；+2/+4 自动让对方摸牌；为轻量化变体，未实现完整竞赛 UNO 的所有特殊质疑和回合规则。
- **恶魔轮盘风格**：纯虚拟概率对决，随机实弹/空弹、生命值、放大镜（查看下一发）、香烟（恢复生命）。只是抽象策略游戏，不包含现实武器操作。
- **双人斗地主**：简化对战版，支持单张、对子、三张、四张炸弹和王炸；尚未支持顺子、连对、飞机、三带等标准牌型。

游戏房间保存在服务器内存中，服务重启会清空。建议 Railway 单实例部署；若扩容多个实例需使用共享持久化数据库/Redis 适配 Socket.IO。已有功能暂未经过完整跨设备上线 QA。
